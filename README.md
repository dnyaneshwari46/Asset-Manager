\# Asset Manager



Asset Manager is a full-stack career and interview preparation platform built with React, TypeScript, Node.js, PostgreSQL, Clerk, and AI integrations.



\## Features



\- Dashboard

\- Resume Builder

\- Resume PDF export

\- Resume / ATS Checker

\- Resume analysis

\- AI mock interviews

\- Role-based interview questions

\- Voice-based interview interaction

\- Interview scoring and feedback

\- Coding Arena

\- JavaScript, TypeScript, Python, and Java coding support

\- Online code execution and judging

\- PostgreSQL database

\- Clerk authentication

\- Responsive user interface



\## Technology Stack
